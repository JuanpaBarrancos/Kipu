# Kipu

Kipu ayuda a pequeños negocios de Bolivia a cerrar la caja en 2 minutos, separar la plata para reponer mercadería, controlar el fiado y ver cuánto cuestan sus deudas. Funciona sin cuenta, sin NIT y sin servidor: los datos se guardan solo en el celular de cada comerciante.

- App: el enlace aparece en Settings → Pages de este repositorio.
- Guía de publicación e instalación: [LEEME.md](LEEME.md)
